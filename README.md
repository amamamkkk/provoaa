# Анти-Террор

Система детекции опасных и подозрительных людей на видеокамерах.

- **Красная обводка** — обнаружено оружие (нож, пистолет, винтовка и т.д.)
- **Жёлтая обводка** — возможно оружие / подозрительный объект (низкая уверенность модели)
- **Зелёная обводка** — обычный человек

## 1.1 Как и на чём обучить ИИ

Используется **YOLO11** (односторонняя свёрточная сеть для детекции объектов в реальном времени).
Обучение делается не с нуля, а **дообучением** (fine-tuning) готовой модели — это в разы быстрее
и требует меньше данных (обычно 2000–5000 размеченных изображений).

### Где взять данные (размеченные датасеты оружия)

1. **Roboflow Universe** — https://universe.roboflow.com — в поиске наберите
   `weapon detection`, `knife detection`, `guns`. Оттуда датасет можно скачать в формате YOLOv8
   в 2 клика (нужна бесплатная регистрация).
2. **Kaggle** — https://www.kaggle.com — запросы `weapons dataset`, `knife gun dataset`.
3. Свои данные: наснимайте фото/кадры из видео, разметьте инструментом
   **LabelImg** или **Roboflow Annotate** в формате YOLO (txt-файлы с классами и координатами).

Минимум классов для старта: `knife`, `gun`, `pistol`, `rifle` + `person` (для обводки людей).

### Подготовка датасета

Структура папки (создаётся автоматически, если качаете с Roboflow):

```
datasets/weapon_dataset/
├── data.yaml          # описание классов и путей
├── train/images/*.jpg
├── train/labels/*.txt
├── valid/images/*.jpg
└── valid/labels/*.txt
```

`data.yaml`:
```yaml
names:
  0: person
  1: knife
  2: gun
  3: pistol
  4: rifle
nc: 5
path: ../weapon_dataset
train: train/images
val: valid/images
```

### Обучение

**Рекомендуемый путь — Google Colab** (бесплатный GPU T4, в ~6 раз быстрее, чем RTX 2050):
открой ноутбук `анти_террор.ipynb` → запусти ячейки → скачай `best.pt` → положи в `weights/weapon_detection.pt`.

**Локально на своей GPU** (RTX 2050 = ~11 мин/эпоха, 50 эпох ≈ 9 часов — гнать на ночь):

```
pip install -r requirements.txt
python train.py --model yolo11s.pt --epochs 50 --batch 8 --device 0
```

Результат: `weights/weapon_detection.pt`.

На Windows обязательно оставьте `workers=0` (уже стоит в train.py), иначе
загрузчик данных с multiprocessing зависает. Точнее (но медленнее): `yolo11m.pt`.

## 1.2 Как внедрить обученную модель в код

1. Положите обученные веса в `weights/weapon_detection.pt`.
2. Модель загружается в `detector.py` (`WeaponDetector.__init__`) через библиотеку
   `ultralytics` — она сама разбирает веса и выполняет предсказания.
3. `detect()` прогоняет кадр через модель, а `_classify()` присваивает уровень:
   - класс оружия с высокой уверенностью (`conf >= weapon_high`) → **danger** (красный);
   - оружие с низкой уверенностью (`weapon_low <= conf < weapon_high`) → **warning** (жёлтый);
   - всё остальное, включая людей → **normal** (зелёный).
4. `draw_detections()` рисует рамки нужным цветом, `main.py` получает кадры с камеры
   и подаёт их в `analyze()`.

Если в вашем датасете другие имена классов оружия — добавьте их в словарь `WEAPON_CLASSES`
в `detector.py`, и обводка подхватится автоматически.

## Запуск

```bash
pip install -r requirements.txt

# Веб-камера (источник по умолчанию: 0)
python main.py

# Файл фото/видео
python detect.py test.mp4
python detect.py test.jpg
```

### Настройка `config.yaml`

| Параметр          | Значение                     | Описание                                   |
|-------------------|------------------------------|--------------------------------------------|
| `model_path`      | `weights/weapon_detection.pt`| путь к весам                               |
| `source`          | `0` или `"rtsp://…"`         | камера, видео или поток RTSP               |
| `weapon_high`     | `0.45`                       | порог уверенности для красной рамки        |
| `weapon_low`      | `0.25`                       | порог для жёлтой рамки                     |
| `save_alerts`     | `true`                       | сохранять снимки тревог в папку `alerts/`  |
| `alert_sound`     | `false`                      | звуковой сигнал при обнаружении оружия     |

## Как это работает по кадрам

1. Кадр с камеры → `detector.detect()` → модель возвращает рамки + класс + уверенность.
2. `_classify()` решает цвет рамки по правилам выше.
3. `draw_detections()` рисует рамки и подписи.
4. При обнаружении оружия кадр сохраняется в `alerts/` как улика.
